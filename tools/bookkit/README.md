# bookkit · OCR 文本到可读电子书

一本书的完整重排流水线：**断句分段 → 章节分层 → 清噪校错 → 三格式输出（Markdown / HTML / EPUB）**。
原则是不改观点、只做排版；所有判断都以「行级」为粒度写进规格文件，跑一次即可复现。

## 一、三步跑通下一本书

```bash
# 1. 准备：把 OCR 出来的 Markdown 放到任意位置
# 2. 写规格：复制一份 specs/01_毒教育.yml 改章节结构、噪声行、错字表
# 3. 跑
python3 bookkit.py specs/新书.yml --src /path/to/新书.md --out /path/to/输出目录
```

产出：

| 文件 | 用途 |
| --- | --- |
| `<书名>-精排版.md` | 带封面信息与目录的 Markdown，便于存档、二次编辑 |
| `<书名>-精排版-正文.md` | 去掉前置信息的纯正文，喂给 pandoc / EPUB |
| `<书名>.html` | 单文件网页版：字体已子集化内嵌，手机单栏、桌面侧栏目录 |
| `<书名>.epub` | 白底 EPUB，两级目录 |

依赖：`pandoc`、`pyyaml`、`fonttools` + `brotli`（字体子集化）、系统里的 Noto Serif/Sans CJK。

## 二、规格文件字段

```yaml
book: {title: 书名, subtitle: 副题, author: 作者, lang: zh-CN}
preface: "转版声明文字"          # 可选，写进 md 的引言块
front_matter: "## 出版说明\n\n..."  # 可选，写进 html/epub 的开头
noise_lines: [472, 474]          # 整行丢弃（片头乱码、广告漫画等）
noise_substr: ["薇芯[:：]\\s*\\d+", "贴贴"]   # 正则抹掉行内水印
manual:                          # 行号 → 人工改写后的整行
  658: "标题‖‖正文……"
fix_map: [["大學", "大学"]]       # 全文错字替换
chapters:
  - title: 章名
    sections:
      - [10, "节名"]              # [行号, 节标题]
      - [30, "节名", "该行正文首句"]  # 第三项：标题行里夹着的正文，单独补回
manual_start: {"3": 440}         # 无小节章的起始行，人工指定
pack: {lo: 170, hi: 330}         # 成段阈值：段长不足 lo 继续并入，超过 hi 断开
```

### 行内约定（人工改写时用）

- `‖` 分隔「题记 / 提问 / 正文」多块，第一块渲染成引用块
- `‖p‖` 只切段落，不切引用块
- `‖‖` 前一块作小节标题，后一块作正文
- `⁂` 一行拆成多条：以 `- ` 或编号开头的成列表项，其余成段

## 三、模板与样式

- `book.html`：HTML 外壳（封面 / 目录 / 正文三段占位）
- `book.css`：书籍级排版样式，含 `{{SERIF}}`、`{{SANS}}` 两个字体占位符
- `epub.css`：EPUB 用的精简样式（阅读器兼容优先，不用 clamp / text-spacing 等新特性）

改字体：换 `bookkit.py` 里的 `--serif-ttc / --sans-ttc`，子集化按全书用字自动生成。
改版式：只动 `book.css`，HTML 与后续书全部生效。

## 四、每次排版后的自检

```bash
# 结构统计会随运行打印：章 / 节 / 段 / 列表项 / 字数 / 最长段
# 硬指标：最长段 ≤ 330 字；水印关键词零命中；章首不吞正文
grep -c "薇芯\|公众号\|贴贴" 输出.md   # 应为 0
```

## 五、已知取舍

- HTML 内嵌字体约 1.2–1.8 MB，换来离线也是宋体；不要字体可加 `--no-html` 后手工引用 `book.css`。
- EPUB 不嵌字体（体积优先），字体交给阅读器；要嵌字体用 `--epub-embed-font` 自行加参数。
- 章节切分依赖行号，OCR 文本一变（重跑识别）就要重写 `chapters` 与噪声行号。
